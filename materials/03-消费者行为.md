# 第 3 章 消费者行为

> 营销做得好不好，最终要看消费者买不买。而要让人买，先要懂他为什么会买。

## 学习目标

学完本章后，你应该能够：

1. 描述消费者购买决策的五个阶段。
2. 列举影响消费者行为的四类因素。
3. 用马斯洛需求层次理解购买动机。
4. 区分不同类型的购买决策及其营销含义。

## 3.1 消费者购买决策过程

一个典型的购买决策要经历五个阶段（注意：并非每次都走完全程）：

1. **问题识别**：察觉到「理想状态」与「现实状态」有差距（我饿了）。
2. **信息搜索**：主动了解可选方案（内部记忆 + 外部搜索）。
3. **方案评估**：比较不同品牌/产品的属性（价格、口碑、功能）。
4. **购买决策**：决定买哪个、在哪买、何时买。
5. **购后行为**：使用后的满意或不满，影响口碑与复购。

营销者要在**每一个阶段**找到「帮消费者一把」的切入点：制造问题意识、让信息容易被找到、突出关键属性、降低购买阻力、做好售后。

## 3.2 影响消费者行为的因素

消费者的选择受四类因素影响：

1. **文化因素**：文化、亚文化、社会阶层。这是最广泛、最深层的影响。
2. **社会因素**：家庭、朋友、参照群体、意见领袖。
3. **个人因素**：年龄、职业、经济状况、生活方式、个性。
4. **心理因素**：动机、感知、学习、信念与态度。

> 记住顺序：文化 → 社会 → 个人 → 心理，影响从宏观到微观。

## 3.3 动机与马斯洛需求层次

消费者为什么买？源于**动机**——一种被激发的、指向目标的需要。马斯洛把人的需要从低到高排成五层：

1. 生理需要（吃、穿、住）
2. 安全需要（人身、财产、健康）
3. 社交需要（归属、友谊、爱）
4. 尊重需要（自尊、地位、认可）
5. 自我实现需要（发挥潜能、实现理想）

一般规律：**低层次需要基本满足后，才会追求更高层次**。营销者据此定位产品满足的是哪一层需求——同样一个包，可以卖「装东西」（功能），也可以卖「身份」（尊重）。

## 3.4 购买决策的类型

按消费者「卷入程度」和「品牌间差异」高低，可以把购买分为四类：

| | 品牌差异大 | 品牌差异小 |
| --- | --- | --- |
| **高卷入** | 复杂购买（买手机、买车） | 减少失调（买贵价但差异不明显的商品） |
| **低卷入** | 寻求多样（换口味买零食） | 习惯性购买（买牙膏） |

营销含义：复杂购买需要提供**充足可信的信息**；习惯性购买则要靠**渠道覆盖、促销和熟悉感**让消费者「不加思考地选你」。

## 小案例：为什么结账口摆着口香糖和巧克力

超市把口香糖、巧克力、小玩具放在收银台附近，瞄准的是「**低卷入、冲动型**」的购买：消费者排队等待时不用深思熟虑，随手就拿。这就是利用「低卷入习惯性购买」特点的典型陈列策略。

## 课堂讨论

1. 回忆你最近一次「复杂购买」（如买电脑/手机），对应五个决策阶段各做了什么？
2. 分析一款你熟悉的商品，它主要满足马斯洛哪一层的需要？它的广告是怎么暗示这一点的？

## 关键术语

- **购买决策过程**：问题识别 → 信息搜索 → 方案评估 → 购买决策 → 购后行为。
- **参照群体**：影响个人态度和行为的群体。
- **马斯洛需求层次**：生理、安全、社交、尊重、自我实现。
- **卷入程度**：消费者对某次购买重视和投入的程度。
- **复杂购买 / 习惯性购买**：高卷入大差异 / 低卷入小差异的购买类型。
