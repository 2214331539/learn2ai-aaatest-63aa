# 第 2 章 营销环境分析

> 企业不是孤岛，它的每一个决策都发生在不断变化的环境之中。看不清环境，营销就无从谈起。

## 学习目标

学完本章后，你应该能够：

1. 区分营销的微观环境与宏观环境。
2. 用 PEST 框架分析宏观环境。
3. 用 SWOT 框架把环境分析转化为战略判断。
4. 理解环境「不可控」却「可监测、可应对」的特点。

## 2.1 营销环境：微观与宏观

**营销环境**指影响企业营销活动的所有外部力量，分为两个层次：

- **微观环境**：与企业关系密切、直接影响其服务顾客能力的因素，如供应商、中间商、顾客、竞争者、公众。
- **宏观环境**：更广泛、企业难以控制的社会力量，如人口、经济、技术、政治法律、社会文化、自然环境。

微观环境企业可以「部分影响」，宏观环境企业只能「监测并适应」。

## 2.2 宏观环境：PEST 分析

PEST 是分析宏观环境最常用的框架：

| 维度 | 关注点 | 例子 |
| --- | --- | --- |
| **P（政治法律）** | 政策、法规、监管 | 数据隐私法、行业准入 |
| **E（经济）** | 经济周期、收入、购买力 | 通胀、消费降级/升级 |
| **S（社会文化）** | 人口结构、价值观、生活方式 | 老龄化、单身经济、环保意识 |
| **T（技术）** | 新技术、创新扩散 | 移动支付、AI、直播电商 |

> 使用时不要机械罗列，而要回答：「这些趋势**如何**影响我的市场机会和威胁？」

## 2.3 微观环境中的竞争者

分析竞争时常用**波特五力模型**，它帮助判断一个行业竞争的激烈程度：

1. **现有竞争者的竞争**：行业内对手多不多、强不强。
2. **潜在进入者的威胁**：新玩家进来难不难（壁垒高低）。
3. **替代品的威胁**：有没有别的方式满足同样需求。
4. **供应商的议价能力**：上游能否抬高你的成本。
5. **买方的议价能力**：顾客能否压低你的价格。

五种力量越强，行业利润空间通常越薄。

## 2.4 SWOT：把环境变成决策

**SWOT 分析**把环境扫描的结果落到企业自身，形成四个象限：

| | 有帮助 | 有害 |
| --- | --- | --- |
| **内部（可控）** | S 优势（Strengths） | W 劣势（Weaknesses） |
| **外部（不可控）** | O 机会（Opportunities） | T 威胁（Threats） |

正确的用法不是「列出四个清单」就结束，而是交叉组合成策略：

- **SO 策略**：用优势抓住机会（增长）。
- **WO 策略**：借机会补短板（改进）。
- **ST 策略**：用优势抵御威胁（防御）。
- **WT 策略**：减少劣势、回避威胁（收缩）。

## 2.5 应对环境的思路

环境不可控，但企业可以：

1. **持续监测**：建立环境扫描机制，而不是临时抱佛脚。
2. **保持敏捷**：快速响应变化，而非死守旧计划。
3. **主动影响**：在合规范围内通过公关、游说、标准制定影响环境。

## 小案例：从「方便面」到「外卖」的环境变化

方便面行业一度因人们变忙而增长，但外卖平台的兴起（技术 + 生活方式的变化）成为强有力的**替代品威胁**，直接冲击了传统方便面销量。这提醒我们：真正的威胁往往来自「看似不相关」的行业，环境扫描不能只盯着老对手。

## 课堂讨论

1. 用 PEST 分析你所在城市近五年的一项明显变化，说明它带来了什么市场机会。
2. 给一家小型咖啡店做一份 SWOT，并给出至少一条 SO 和一条 WT 策略。

## 关键术语

- **营销环境**：影响企业营销的外部力量总和。
- **微观环境 / 宏观环境**：直接影响因素 / 广泛社会力量。
- **PEST 分析**：政治法律、经济、社会文化、技术四维宏观分析。
- **波特五力模型**：分析行业竞争强度的五种力量。
- **SWOT 分析**：优势、劣势、机会、威胁的组合分析。
