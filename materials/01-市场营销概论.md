# 第 1 章 市场营销概论

> 营销不是「把东西卖出去」这么简单，而是从理解顾客需求开始的整体经营活动。

## 学习目标

学完本章后，你应该能够：

1. 说出市场营销的定义，并区分「需要、欲望、需求」三个概念。
2. 说明五种营销观念的演变脉络。
3. 理解 4P（市场营销组合）的基本含义。
4. 用自己的话解释「顾客价值」与「顾客满意」的关系。

## 1.1 什么是市场营销

**市场营销（Marketing）** 的通俗理解是「卖东西」，但学术上它远不止如此。美国市场营销协会（AMA）给出的定义强调：市场营销是「创造、传播、传递和交换对顾客、客户、合作伙伴以及整个社会有价值的产品/服务的一系列活动、机构和过程」。

抓住三个关键词：

- **价值**：营销的起点是创造价值，而不是制造产品。
- **交换**：买卖双方自愿交换各自认为有价值的东西。
- **顾客为中心**：一切活动围绕顾客的需求展开。

> 一句话：市场营销 = 通过满足顾客需求来实现组织目标。

## 1.2 需要、欲望与需求

这是营销学最基础、也最容易被混淆的三个概念：

| 概念 | 含义 | 例子 |
| --- | --- | --- |
| **需要（Need）** | 人类感到缺乏某种东西的状态，是天生的 | 口渴、饥饿、社交 |
| **欲望（Want）** | 需要被文化和个性塑造成的具体形式 | 口渴时想喝可乐而不是白水 |
| **需求（Demand）** | 有购买力支撑的欲望 | 想喝可乐，且买得起 |

营销者**不能创造需要**（需要本来就有），但可以**影响欲望**，并通过产品把欲望转化为可满足的需求。

## 1.3 营销观念的演变

企业对市场的态度经历了五个阶段，理解这段历史有助于明白「顾客导向」从何而来：

1. **生产观念**：消费者喜欢买得到、买得起的产品 → 企业专注提高产量、降低成本。
2. **产品观念**：消费者喜欢质量最好、性能最优的产品 → 企业专注打磨产品。
3. **推销观念**：消费者不会主动买，需要强力推销 → 企业专注广告和销售技巧。
4. **营销观念**：先弄清顾客要什么，再去生产 → 企业专注满足顾客需求。
5. **社会营销观念**：在满足顾客的同时兼顾社会长远利益 → 企业平衡「顾客、企业、社会」三方。

> 判断一家企业处于哪种观念，看它的问题是「我们怎么把产品卖出去」（推销观念）还是「顾客真正需要什么」（营销观念）。

## 1.4 市场营销组合：4P

**市场营销组合（Marketing Mix）** 是企业可以控制、用来影响顾客的一组工具，经典的划分是 4P：

| 4P | 中文 | 核心问题 |
| --- | --- | --- |
| **Product** | 产品 | 提供什么样的产品/服务？ |
| **Price** | 价格 | 定价多少？顾客如何付费？ |
| **Place** | 渠道 | 在哪里、通过什么方式买到？ |
| **Promotion** | 促销（传播） | 如何让顾客知道并愿意买？ |

4P 是企业视角，对应地从顾客视角看就是 4C：**顾客价值（Customer Value）、成本（Cost）、便利（Convenience）、沟通（Communication）**。成功的营销是让 4P 与 4C 相互匹配。

## 1.5 顾客价值与顾客满意

- **顾客感知价值**：顾客比较「得到的好处」与「付出的代价」后形成的整体评价。
- **顾客满意**：顾客把实际体验与期望做比较后的感受。**满意 = 实际 ≥ 期望**。

企业要追求的是「可盈利地让顾客满意」——既要让顾客满意，也要让企业赚钱，这是营销的核心平衡。

## 小案例：手机卖的不是「手机」

同一部智能手机，为什么有人愿意为某个品牌多付上千元？因为它卖的不仅是通话和上网（功能价值），还有身份认同、设计审美、售后保障（情感与社会价值）。这就是从「卖产品」到「卖价值」的区别。

2. 一家只强调「我们的产品质量最好」却卖不动的企业，可能犯了哪种观念的问题？如何转向营销观念？

## 关键术语

- **市场营销（Marketing）**：创造并传递顾客价值、通过交换满足各方需求的活动与过程。
- **需要 / 欲望 / 需求**：天生的缺乏状态 / 需要的具体形式 / 有购买力支撑的欲望。
- **市场营销组合（4P）**：产品、价格、渠道、促销。
- **顾客感知价值**：顾客对所得与所失的整体评价。
- **顾客满意**：实际体验与期望的比较结果。
