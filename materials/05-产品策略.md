# 第 5 章 产品策略

> 产品是营销组合里最基础的一环——没有「对的产品」，价格、渠道、促销再努力也无从谈起。

## 学习目标

学完本章后，你应该能够：

1. 区分产品的三个层次。
2. 说明消费品与工业品的分类。
3. 描述产品生命周期的四个阶段及对应策略。
4. 理解产品组合、产品线和品牌的关系。

## 5.1 产品的三个层次

营销中的「产品」不只是实物本身，而是顾客获得的**整体价值**，分三层：

1. **核心产品**：顾客真正买的是什么（利益）——买口红，买的是「美丽与自信」。
2. **形式产品**：看得见的部分——质量、设计、包装、品牌、功能。
3. **附加产品**：额外的服务与利益——保修、送货、售后、分期。

> 记住：顾客买的是「核心利益」，形式与附加层是为了更好传递和强化这个利益。

## 5.2 产品的分类

按购买者不同，产品分两大类：

- **消费品**（卖给最终消费者）：
  - **便利品**：频繁购买、低价、不比较（牙膏、饮料）。
  - **选购品**：会花时间比较价格与质量（服装、家电）。
  - **特殊品**：有独特品牌偏好、愿意费力寻找（奢侈品、特定型号）。
  - **非渴求品**：平时不想、遇到才知道（保险、墓地）。
- **工业品**（卖给企业用于再生产）：原材料、设备、零部件、服务等。

分类的意义在于：不同类型的产品，其分销、促销、定价策略完全不同。

## 5.3 产品生命周期（PLC）

产品像生命一样有生老病死，典型经历四个阶段：

| 阶段 | 特征 | 营销重点 |
| --- | --- | --- |
| **导入期** | 销量低、成本高、利润低甚至亏 | 建立认知、教育市场 |
| **成长期** | 销量快速上升、竞争者进入 | 扩大市场、建立品牌 |
| **成熟期** | 增速放缓、竞争激烈、利润见顶 | 差异化、保卫份额 |
| **衰退期** | 销量与利润下滑 | 收割、改良或退出 |

> PLC 不是宿命：好的营销可以延长成熟期（改包装、新用途、新市场），也能用新产品迭代老产品。

## 5.4 产品组合与产品线

- **产品线**：功能相关、卖给同一类顾客的一组产品（如某品牌的洗发水、护发素、沐浴露）。
- **产品组合**：企业全部产品线构成的总集合，用**宽度**（几条线）、**长度**（总产品数）、**深度**（每线的款式数）、**一致性**（线之间关联度）四个维度衡量。

企业通过「增宽/加长/加深」来增长，但也要防止产品线过长导致资源分散。

## 5.5 新产品开发

新产品开发流程：**创意产生 → 创意筛选 → 概念开发与测试 → 营销策略制定 → 商业分析 → 产品开发 → 市场测试 → 商业化**。多数创意会在早期被淘汰，这是为了把资源留给真正有前景的产品。

## 小案例：为什么牙膏要出几十种口味

同一品牌牙膏有美白、抗敏、清新、儿童等多个系列，这就是在**加深产品线**：用不同细分产品满足不同细分需求，占据更多货架空间，同时挤压竞争对手的位置。背后的逻辑正是第 4 章讲的市场细分。

## 课堂讨论

1. 任选一件你常用的商品，拆解它的「核心、形式、附加」三个层次。
2. 判断智能手机处于产品生命周期的哪个阶段？品牌可以靠什么策略延缓衰退？

## 关键术语

- **核心 / 形式 / 附加产品**：产品的三个层次。
- **便利品 / 选购品 / 特殊品 / 非渴求品**：消费品的四种类型。
- **产品生命周期（PLC）**：导入、成长、成熟、衰退。
- **产品线 / 产品组合**：一组相关产品 / 企业全部产品线的集合。
- **新产品开发流程**：从创意到商业化的八步。
