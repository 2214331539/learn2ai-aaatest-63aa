# STP 与营销组合分析

## 任务背景

选择一个你熟悉的产品或品牌（可以是日常消费品、手机 App、餐饮品牌、服饰、电子产品等），运用课程第 4–8 章所学，完成一次完整的营销策略分析。

## 任务要求

请按以下五个部分完成分析：

1. **市场细分（Segmentation）**：为该产品至少识别 2 个细分市场，并说明你使用的细分依据（地理 / 人口 / 心理 / 行为变量）。
2. **目标市场（Targeting）**：说明该品牌选择了哪个（哪些）细分市场，以及采用的覆盖策略（无差异化 / 差异化 / 集中化营销），并简要说明理由。
3. **市场定位（Positioning）**：用一句话写出该品牌的定位陈述，并说明它在目标顾客心中的差异化价值。
4. **营销组合（4P）**：分别从产品、价格、渠道、促销四个角度，分析该品牌是如何落地这一定位的。
5. **结论与建议**：指出该品牌营销中的一个亮点和一个可改进之处，并给出你的理由。

## 评分要点（供参考）

- 细分与目标市场选择是否逻辑自洽、依据清晰。
- 定位陈述是否准确、聚焦，且与 4P 分析一致。
- 分析是否结合了具体事实（而非空泛套用概念）。
- 建议是否有理有据。
